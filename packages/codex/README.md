# nrev-workflows — Codex CLI package

Generated by `scripts/sync-agents.sh` from the canonical `shared/`. Do not edit
`skills/`, `mcp/`, or `AGENTS.md` here — edit `shared/` and re-run the sync.

Contents:
- `skills/` — the 10 nRev domain skills (open Agent Skills format, auto-loaded)
- `mcp/` — the bundled MCP server (stdio, launched via `uv`)
- `AGENTS.md` — always-on context (Codex reads `AGENTS.md` natively)
- `config.toml` — MCP server block for a manual install
- `plugin.json` — Codex plugin manifest (see the verify note below)

Prereqs: Python 3.10+ and [uv](https://docs.astral.sh/uv/) on `PATH`.

## Install — Option A: manual (reliable, recommended today)

1. **Skills** — make them discoverable by Codex:
   ```
   mkdir -p ~/.agents/skills
   cp -R skills/* ~/.agents/skills/         # or symlink for a dev loop
   ```
   Codex auto-discovers any `SKILL.md` under `~/.agents/skills/` (user scope) or
   `.agents/skills/` (repo scope) — no registration needed.
2. **MCP server** — append the block in [`config.toml`](./config.toml) to
   `~/.codex/config.toml`, setting the absolute path to this `mcp/` dir.
3. **Pre-warm** (avoids a first-run startup timeout while uv resolves deps):
   ```
   uv run --quiet --project ./mcp nrev-workflows-mcp   # Ctrl-C once it starts
   ```
4. Start Codex; `/mcp` should list `nrev-workflows`. Ask it to "log in to nrev
   workflows" (the `auth_login` tool) — a browser opens for sign-in once.

## Install — Option B: Codex plugin

`plugin.json` bundles the skills + MCP server as a single installable unit for
the Codex plugin system (Codex CLI ≥ v0.117). Install via the Codex plugin
marketplace / `codex plugin` flow pointing at this package.

> ⚠ **Verify before relying on Option B.** The exact `plugin.json` schema
> (field names, the `${CODEX_PLUGIN_ROOT}` variable, and how a monorepo subdir
> is referenced) is version-specific and not yet smoke-tested against a live
> Codex install. Option A is the guaranteed-working path meanwhile. See the
> design doc's "Open items" section.

## Auth & environment

Sign-in is shared with every other agent: the session lives in
`~/.nrev-workflows/credentials` and auto-refreshes. `NREV_ENV=staging` switches
environments (add it under `env` in the config block).
